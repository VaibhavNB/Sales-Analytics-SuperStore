# Superstore Retail Sales Analytics Dashboard

**End-to-End Data Analytics Project** | Python + Excel + Power BI

## 📊 Project Overview
Built a comprehensive retail sales analytics solution for a global superstore to drive revenue growth and profitability insights. Delivered interactive Power BI dashboard with advanced DAX, RFM customer segmentation (via Python), and Excel validation.

**Key Business Insights Delivered:**
- Identified high-value customer segments using RFM analysis
- Revealed YoY growth trends and category-wise profit margins
- Highlighted underperforming regions/products for optimization
- Potential revenue uplift opportunities quantified

## 🛠️ Tech Stack
- **Python**: Pandas, NumPy (data cleaning, feature engineering, RFM segmentation)
- **Excel**: Power Query, PivotTables, dynamic slicers, KPI cards, YoY growth
- **Power BI**: Star Schema modeling, DAX measures, interactive visuals, Treemap, Matrix

## 📁 Project Structure
- `data/` → Raw & cleaned datasets
- `notebooks/` → Jupyter notebook with EDA + RFM
- `excel/` → Validation workbook with pivots & dashboard
- `powerbi/` → Final .pbix file
- `reports/` → Executive summary PDF

## 🚀 Key Features
- Dynamic KPI cards (Sales, Profit, Margin %, Orders, Avg Shipping Days)
- YoY Growth analysis with time intelligence
- Customer segmentation using RFM (Recency-Frequency-Monetary)
- Regional performance using Treemap + Matrix
- Drill-down capability across Category → Sub-Category
